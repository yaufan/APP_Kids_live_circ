# 小小生活家的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，十首曲子都是為這個 APP 新寫的。只有一個例外：垃圾車放的是貝多芬《給愛麗絲》的第一句，因為台灣的垃圾車就是放這首；這段旋律兩百年前就是公共財（作者過世很久，誰都可以用），播它的音樂盒也是這裡合成的。

- 合成用的小工具（鐘聲、木琴、豎琴、撥弦、玩具小喇叭、接成循環、量音量、人聲的共鳴方法……）是從迷宮小冒險的 `design/sounds/make_sounds.py` 複製過來的（它們又是從更早的兄弟 APP 一路傳下來的）。
- 新做的有：音樂盒、卡林巴（拇指琴）、烏克麗麗（和刷和弦）、玩具木琴、顫音琴、木魚，還有流水、風聲、敲擊、小小人聲這些做音效的積木，十首曲子，和全部的音效。

給 2～5 歲的小朋友，所以**溫柔、像玩具、可愛**，是一個小朋友的家的聲音：沒有刺耳或突然的聲音；地震和打雷都很輕、很短、很低，不嚇人；做錯只是柔柔的「嗯？」。每個聲音 0.3～1.5 秒內就聽得出是什麼。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、破音、接頭）和頻譜圖檢查的；請在手機上聽聽看，覺得哪個不像、不好聽再改。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
python3 design/sounds/make_sounds.py tap yum                # 只重做這幾個（改一個聲音的時候）
```

跑完會印出每個檔案的長度、大小、最大音量、聽起來多大聲、有沒有破音、頭尾的點，背景音樂接頭的檢查，和旋律比伴奏響多少。
- 亂數都用固定的種子，每次跑出來的檔案都一模一樣（一個 byte 都不差）。
- 程式會檢查：檔名剛好是下面這些（資料夾裡沒有別的檔案）、音效不超過 1.5 秒（垃圾車 6 秒、深呼吸 2.2 秒、雨 2.1 秒、坐娃娃車 1.7 秒、呼吸 1.6 秒、沖馬桶 1.6 秒、地震 1.6 秒除外）、背景音樂 18～30 秒、音效頭尾都是 0、沒有破音、背景音樂和雨的接頭沒有「啪」一聲。
- 全部加起來超過 12,000,000 bytes 就會停下來報錯。目前 119 個檔、10,591,668 bytes（約 10.1 MiB），背景音樂佔 7.3 MB。
- 試聽檔是每首背景音樂的前 6 秒，接著每個音效照下面的順序播一次（雨連播三次），中間停一下；會印出每一段從第幾秒開始。

## 格式

- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；音效 22,050 Hz。
- 背景音樂都是整數小節、21～24 秒，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。程式用兩個方法檢查接頭：最後一個點跳回第一個點的差距（要比接頭前後 0.02 秒裡最大的一步小），和接頭前後 0.02 秒的高音（「啪」一聲會在這裡冒出來；要比曲子其他地方最響的一段小很多）。雨也是循環（跑過結尾的雨滴繞回開頭）。
- 音效兩頭都有淡入淡出，第一個和最後一個點都是 0，不會「啪」一聲。
- **音量一樣大**：程式量每個聲音「從手機喇叭聽起來」有多大聲（用耳朵比較敏感的頻率，也就是 A 加權；不算手機放不出來的 250 Hz 以下低音；大約 0.2 秒一段），再把每個聲音調到一樣大聲（約 −21 dB）：該輕一點的就小幾 dB（按鈕 −25、腳步和時鐘 −27、蚊子、地震、雷、雨 −27～−28）。最大音量不超過 0.72（−2.9 dB），沒有破音。
- 很短、很尖的聲音（釦子、剪指甲、安全帶、夾子、走路、拍手）和很低的聲音（心跳、垃圾袋）會被「最大音量」擋住，聽起來比目標再輕 1～7 dB；這些本來就該輕。
- 背景音樂聽起來比音效輕 8～12 dB（早上、白天 −29；下午、外面、幼兒園 −29.5；傍晚、超市 −30.5；診所 −31；晚上 −32；休息 −33），放在念的話和音效下面。
- 每首曲子的旋律比伴奏響 12～18 dB，旋律清楚，伴奏聽得到。
- 手機小喇叭放不出很低的聲音，所以心跳、踢球、垃圾袋、地震、雷、肚子咕嚕這些低低的聲音都加了一點它自己比較高的泛音（`carry`），手機上才聽得到。

## 背景音樂

十首的拍子、調、樂器都不一樣，小朋友一聽就知道現在是什麼時候、在哪裡。都是音樂盒、木琴、鐵琴、卡林巴、烏克麗麗這些玩具般的聲音，簡單、開心；晚上和休息是搖籃曲。
