# 設計（草案）：小小生活家

> 給 2～5 歲小朋友的生活習慣遊戲。這是**建議**，等使用者決定後定案（見最後「要決定的事」）。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 一句話
小朋友幫自己的小角色過一天：看時鐘知道「現在該做什麼」，走到對的房間，用小遊戲完成刷牙、吃飯、上廁所、睡午覺這些事。目的是把真實生活的作息變熟悉、變好玩，而不是在螢幕上玩很久。

## 給誰
- **2～5 歲**，在台灣，國語為主。
- 2 歲：一次一件事，照著點就好；3～5 歲：要自己看時鐘找房間、收玩具、整理書包。
- 不連網、不定位、沒有廣告、沒有帳號（和兄弟 APP 一樣）。

## 練什麼
- **作息和順序**：起床 → 刷牙 → 吃早餐 → 上學……「現在是什麼時間、該做什麼」。
- **自理**：刷牙、洗手、上廁所、穿衣服、收玩具、洗澡，每一樣都是一個小遊戲，動作和真的一樣。
- **身體的訊號**：想上廁所、肚子餓、想睡覺，角色會表現出來，小朋友學會「注意到了就去做」。
- **說出來**：每件事念出名稱和步驟（「先擠牙膏，再刷刷刷」），家長可以加英文。

## 一開始：取名字、選角色
- 第一次打開：家長幫忙輸入**名字**（也可以不打，用「小寶」），遊戲裡會一直念名字：「小明，該刷牙囉！」
- 小朋友自己**選角色**：點一點就好，不用讀字：
  - 髮型（4 種）、膚色（4 種）、衣服顏色（6 種）；
  - 一隻小夥伴跟在旁邊：小狗、小貓、小兔、小鴨（會跟著做同樣的事，很可愛也多一個示範）。
- 之後家長模式可以改名字、改角色，也可以開第二個小朋友（兄弟姊妹各一個）。

## 家：一棟可以看進去的房子
進場是**客廳**。房子像玩具屋一樣，正面打開，每個房間一眼看得到；點房間或點地上的小腳印就走過去：
- **客廳**：主場景，有時鐘、玩具箱、沙發、窗戶（看得到外面的天色：早上、中午、傍晚、晚上）。
- **房間**：床、窗簾、小夜燈、故事書。睡午覺、睡覺、起床、換衣服。
- **廁所**：馬桶、洗手台、鏡子、浴缸。刷牙、上廁所、洗手、洗澡。
- **廚房／餐桌**：吃早餐、吃晚餐、幫忙收碗。
- **門口**：鞋櫃、書包、雨傘。出門上學、出去玩、回家。
- **外面**（出門後）：公園、幼兒園門口，很簡單的一個畫面。

## 時鐘：一直都在，告訴你現在該做什麼
- 畫面上方一直有一個**大時鐘**，不用看數字：時鐘周圍是一圈**圖案**（太陽＝起床、牙刷＝刷牙、碗＝吃飯、書包＝上學、球＝出去玩、月亮＝睡覺），指針指到哪個圖案，就是現在該做的事。圖案會發亮、小角色會往那個房間看。
- **點時鐘可以調時間**：時鐘變大，小朋友轉指針（或點圖案），時間就跳到那個時段，任務跟著換。這是給小朋友「我想玩睡覺那段」用的，也給家長示範「等一下就是刷牙時間囉」。
- **家長可以設「跟著真的時間」**：時鐘走手機的真實時間，APP 就變成作息提醒：早上打開就是起床刷牙，晚上打開就是洗澡睡覺。預設關（遊戲自己的一天 10 分鐘走完）。
- 一天的順序（建議，家長模式可以關掉不要的）：
  1. 起床（開窗簾、伸懶腰）
  2. 刷牙、洗臉
  3. 換衣服（看窗外天氣選衣服）
  4. 吃早餐
  5. 上學（整理書包、出門、坐娃娃車）
  6. 回家、洗手
  7. 吃午餐
  8. 睡午覺
  9. 出去玩（公園）
  10. 回家洗手、收玩具
  11. 吃晚餐
  12. 洗澡
  13. 刷牙、上廁所
  14. 聽故事、睡覺（關燈，整個家變暗，一天結束）

## 偶爾會發生的事（不在時鐘上）
角色會自己有需要，小朋友要注意到：
- **想上廁所**：角色夾腿扭來扭去、頭上出現小水滴，說「我想尿尿」→ 帶去廁所。做完有「成功！」的小慶祝；2 歲版也教「有感覺就要說」。
- **肚子餓**：肚子咕嚕叫 → 去廚房吃點心（水果）。
- **想睡覺**：打哈欠 → 去房間休息。
- **弄髒了**：出去玩回來衣服髒髒 → 洗澡或換衣服。
- **下雨了**：窗外下雨 → 出門要拿雨傘、穿雨鞋。
這些一天出現 2～3 次，不會一直打擾；2 歲版出現時會直接把路點亮。

## 小遊戲（每件事一個，都是點和拖，不會失敗、沒有倒數）
| 事情 | 房間 | 怎麼玩 |
|---|---|---|
| 起床 | 房間 | 點窗簾拉開，太陽照進來；點角色，牠伸懶腰、跳下床 |
| 刷牙 | 廁所 | 擠牙膏到牙刷上，牙刷在牙齒上來回刷，泡泡越來越多；拿杯子漱口「噗～」 |
| 洗臉、洗手 | 廁所 | 開水龍頭、壓洗手乳、搓搓搓（泡泡）、沖乾淨、擦毛巾 |
| 上廁所 | 廁所 | 脫褲子（點一下）、坐上馬桶、等一下（角色哼歌）、按沖水、洗手 |
| 換衣服 | 房間 | 看窗外天氣（太陽／雨／冷），從衣櫃挑衣服拖到角色身上；穿錯會打噴嚏或流汗，再換 |
| 吃飯 | 廚房 | 把菜拖到盤子裡（練均衡：飯、菜、肉、水果各一），用湯匙餵，吃完擦嘴、碗拿去水槽 |
| 上學 | 門口 | 把書包要帶的三樣東西放進去（水壺、手帕、聯絡簿）、穿鞋、揮手，娃娃車來了 |
| 出去玩 | 外面 | 公園裡選一樣玩（溜滑梯、盪鞦韆、踢球），玩一下回家，身上髒髒的 |
| 收玩具 | 客廳 | 玩具散在地上，一個一個拖進玩具箱（練分類：車子一箱、積木一箱） |
| 洗澡 | 廁所 | 放水、泡泡、沖水、擦乾、吹頭髮 |
| 睡午覺／睡覺 | 房間 | 拉窗簾、關燈、蓋被子、點故事書聽一段小故事、角色睡著，整個畫面慢慢變暗 |

## 獎勵：好習慣貼紙表
- 每做完一件事，貼紙表上那一格貼上一張貼紙（像幼兒園的集點表）。
- 一天全部做完，小夥伴會送一樣房間的裝飾（新的床單、牆上的畫、窗邊的小盆栽），家慢慢變漂亮。
- 沒有排名、沒有扣分。

## 每次玩多久
- 家長設定，**預設 15 分鐘**。時間到了小角色也要睡覺，整個家變暗，要家長解開或等一個小時才能再玩。而且 APP 會說：「換你去做了！」把小朋友帶回真實生活。

## 家長模式（要過家長關卡）
- 名字、角色、第二個小朋友。
- 年齡（難度）、每次玩多久、時鐘是否跟著真的時間、要哪些作息（例如沒有上學就關掉）。
- 看每天做完哪些事、最常跳過哪一項。
- 聲音、念出來、英文。
- 以後的完整版購買只在這裡。

## 畫風（三個方向，草圖見 `docs/mockups/0_畫風選擇.png`）
要和七個兄弟 APP 都不一樣（粗黑框貼紙、水彩繪本、黏土、寫實／色塊、三種卡通、等角小模型／孔版／蠟筆、羊毛氈／像素／果凍），而且房子要能「打開來看每個房間」：
- **A 木頭玩具屋風（建議）**：像木頭娃娃屋，房子正面打開看到每個房間，家具是圓角的木頭積木，有木紋和一點點漆的質感。角色像木頭小人偶，可以換髮型和衣服。溫暖、整齊，房間一眼分清楚。
- **B 立體書風**：像翻開的立體書，房間一層一層立起來，紙的厚度和影子。
- **C 色鉛筆塗畫風**：像小朋友用色鉛筆畫的家，有鉛筆筆觸和紙的紋路，溫溫的。

## 聲音
- 每個時段有不同的背景音樂（早上輕快、中午活潑、晚上安靜的搖籃曲）。
- 每個動作有音效：刷牙沙沙、水龍頭、沖馬桶、吃飯「嗯～好吃」、拉窗簾、關燈「喀」、打哈欠、肚子咕嚕。
- 小夥伴有自己的叫聲。
- 全部用程式合成。

## 技術（和兄弟 APP 一樣）
- Flutter、Riverpod、flutter_svg、audioplayers、flutter_tts；存檔是一個 JSON 檔。
- 點和拖都用原始的手指事件（`Listener`）。
- 圖用 Python 畫 SVG（一份幾何，可以畫成三種畫風），聲音用 numpy 合成。
- 資安和兄弟 APP 一樣：不接受別的 APP 傳來的頁面、家長模式只能從家長關卡進去、不要任何權限。名字只存在手機裡。

## 以後上架和收費（和兄弟 APP 一樣）
- 免費下載：起床、刷牙、吃飯、睡覺四件事。
- 一次買斷完整版：全部作息和房間裝飾。購買只在家長模式。

## 版本計畫（建議）
- **0.1**：取名選角色、五個房間、時鐘、14 件事的小遊戲、偶爾發生的事、貼紙表、休息時間、家長模式、音樂和音效、APP 圖示。
- **0.2**：第二個小朋友、更多裝飾、生日和節日（過年、中秋）。
- **0.3**：家長自己加一件事（例如「吃藥」「餵魚」）、英文。

## 要決定的事
1. 名稱：「小小生活家」（你取的，建議就用它）。
2. 畫風：A 木頭玩具屋（建議）、B 立體書、C 色鉛筆塗畫；只要一種，還是三種都有可以換？
3. 年齡：2～5 歲，兩個難度（小小 2～3、大 4～5）可以嗎？（作息遊戲不太需要三級。）
4. 作息：上面 14 件事都要嗎？有沒有要加或拿掉的（例如沒有上幼兒園）？
5. 偶爾發生的事：想上廁所、肚子餓、想睡覺、弄髒、下雨，都要嗎？
6. 時鐘「跟著真的時間」：預設關、家長可以開，可以嗎？
7. 小夥伴：小狗、小貓、小兔、小鴨，四個可以嗎？
8. 每次玩多久：預設 15 分鐘，家長可以調？
9. 授權：和之前一樣（非商業使用）？（這個專案現在是 Apache 2.0，要換掉。）
