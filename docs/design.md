# 設計：小小生活家

> 給 2～5 歲小朋友的生活習慣遊戲。2026-11-08 定案（見最後「已經決定的事」）。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 一句話
小朋友幫自己的小角色過一天：看時鐘知道「現在該做什麼」，走到對的房間，用小遊戲完成刷牙、吃飯、上廁所、睡午覺這些事。目的是把真實生活的作息變熟悉、變好玩，而不是在螢幕上玩很久。

## 給誰
- **2～5 歲**，在台灣，國語為主。
- 兩個難度：**小小**（2～3 歲）一次一件事、該去的房間和門會點亮、角色自己走過去；**大**（4～5 歲）自己看時鐘找房間，小遊戲多一步（例如穿衣服要扣釦子、吃飯要先擺碗筷）。
- 不連網、不定位、沒有廣告、沒有帳號（和兄弟 APP 一樣）。

## 練什麼
- **作息和順序**：起床 → 刷牙 → 吃早餐 → 上學……「現在是什麼時間、該做什麼」。
- **自理**：刷牙、洗手、上廁所、穿衣服、收玩具、洗澡，每一樣都是一個小遊戲，動作和真的一樣。
- **身體的訊號**：想上廁所、肚子餓、想睡覺，角色會表現出來，小朋友學會「注意到了就去做」。
- **說出來**：每件事念出名稱和步驟（「先擠牙膏，再刷刷刷」），家長可以加英文。

## 一開始：取名字、選角色
- 第一次打開：家長幫忙輸入**名字**（也可以不打，用「小寶」），遊戲裡會一直念名字：「小明，該刷牙囉！」
- 小朋友自己**選角色**：點一點就好，不用讀字：
  - 髮型（4 種）、膚色（4 種）、衣服顏色（6 種）；
  - 一隻小夥伴跟在旁邊：小狗、小貓、小兔、小鴨（會跟著做同樣的事，很可愛也多一個示範）。
- 之後家長模式可以改名字、改角色，也可以開第二個小朋友（兄弟姊妹各一個）。

## 家：一次一個房間，滿滿一個畫面
手機螢幕小，所以**一個畫面只有一個房間**，東西畫得大大的，小朋友好看也好點。進場是**客廳**。
- 怎麼走到別的房間：畫面左右邊緣有**門或箭頭**（點了就走過去，有開門聲和腳步聲）；畫面最下面有一排**小房間圖示**（客廳、房間、廁所、廚房、門口、陽台），點哪個就去哪個；該去的那個房間會發亮、跳一跳。2～3 歲：角色會自己往該去的房間走，只要點牠或點發亮的門。
- 房子的順序（左右相鄰）：陽台 — 廚房 — 客廳 — 門口；客廳上樓是房間和廁所（樓梯在客廳右邊）。出門從門口出去。
- **客廳**：主場景，有沙發、玩具箱、電話、窗戶（看得到外面的天色和天氣）、樓梯。
- **房間**：床、窗簾、小夜燈、故事書、衣櫃、身高尺。
- **廁所**：馬桶、洗手台、鏡子、浴缸、毛巾。
- **廚房／餐桌**：冰箱、餐桌、水槽、碗筷。
- **門口**：鞋櫃、書包、雨傘、安全帽、大門。
- **陽台**：盆栽、曬衣架、小夥伴的碗、垃圾桶和回收桶。
- 房子的全貌只在兩個地方看得到：貼紙表那頁的小圖（看今天家變漂亮了沒），和睡覺時「整個家慢慢變暗」的小動畫。

## 外面：出門可以去的地方
門口出去是一條小街，點就去（0.1 做前四個，其他以後加）：
- **公園**：溜滑梯、盪鞦韆、沙坑、踢球；要過馬路（紅綠燈）才到。
- **幼兒園**：放書包、和老師同學打招呼、上課（唱歌、畫畫）、吃點心、午睡、放學排隊。
- **超市**：推推車、照購物清單找東西（認水果、蔬菜、牛奶）、排隊付錢、把東西放進袋子。
- **診所**：感冒時去。量體溫、看喉嚨「啊～」、打針不怕（深呼吸）、拿藥、貼貼紙。
- 以後：**阿公阿嬤家**（週末去，餵雞、吃飯）、**圖書館**（借書、小聲）、**游泳池**、**坐捷運和公車**、**理髮店**。

## 時鐘：一直都在，告訴你現在該做什麼
- 畫面上方一直有一個**大時鐘**，不用看數字：時鐘周圍是一圈**圖案**（太陽＝起床、牙刷＝刷牙、碗＝吃飯、書包＝上學、球＝出去玩、月亮＝睡覺），指針指到哪個圖案，就是現在該做的事。圖案會發亮、小角色會往那個房間看。
- **點時鐘可以調時間**：時鐘變大，小朋友轉指針（或點圖案），時間就跳到那個時段，任務跟著換。
- 時鐘走遊戲自己的時間（一天大約 10 分鐘走完），**不跟手機的真實時間**（使用者決定）。
- **有星期**：時鐘旁邊有小月曆。星期一到五是上學的一天，**週末**不一樣：睡晚一點、去超市、去公園久一點、去阿公阿嬤家（以後）。學會「今天星期幾」「明天要不要上學」。
- **有天氣和季節**：窗外會變。晴天戴帽子、雨天拿雨傘穿雨鞋、冷天穿外套、熱天擦汗多喝水、颱風天在家玩（不出門）。學會看天氣選衣服。

### 平日的一天（家長模式可以關掉不要的）
1. 起床（開窗簾、伸懶腰）
2. 刷牙、洗臉
3. 換衣服（看窗外天氣選衣服）
4. 吃早餐
5. 上學（整理書包、穿鞋、出門、坐娃娃車）
6. 在幼兒園（打招呼、上課、吃點心、午睡、排隊放學）
7. 回家、洗手、脫鞋放好
8. 吃點心、喝水
9. 出去玩（公園，過馬路看紅綠燈）
10. 回家洗手、收玩具
11. 幫忙做一件家事
12. 吃晚餐、幫忙收碗
13. 洗澡、吹頭髮
14. 刷牙、上廁所
15. 聽故事、說晚安、睡覺（關燈，整個家變暗）

### 週末的一天
睡晚一點 → 吃早餐 → 去超市買菜 → 回家一起煮飯 → 午睡 → 公園玩久一點 → 洗澡 → 睡覺。

## 偶爾會發生的事（不在時鐘上，一天 2～4 次）
角色自己會有需要或遇到事情，小朋友要注意到、想一想怎麼辦：
- **身體的訊號**：想尿尿（夾腿、頭上小水滴）、肚子餓（咕嚕叫）、想睡（打哈欠）、口渴（嘴巴乾乾）、流汗（擦汗、喝水）、冷（發抖，加外套）。
- **身體不舒服**：打噴嚏流鼻水 → 擦鼻涕、多喝水、去診所；跌倒擦傷 → 洗乾淨、貼 OK 繃、秀秀；蚊子咬 → 擦藥不要抓。
- **家裡的事**：門鈴響（郵差送包裹、阿嬤來了，要說「你好」）；電話響（阿公打來，要說話）；停電（找手電筒，不怕黑）；垃圾車的音樂來了（趕快拿垃圾去倒）；小夥伴餓了、要散步、要洗澡；盆栽枯了要澆水；玩具壞了（拿去請爸爸修）。
- **天氣**：突然下雨（收衣服！）；打雷（抱抱、不怕）；**地震**（躲到桌子下，保護頭，台灣小朋友要學）。
- **心情**：小夥伴搶玩具（學分享、輪流）；拼圖拼不好生氣（深呼吸三次）；弄倒牛奶（說對不起、一起擦）；同學哭了（遞衛生紙、拍拍）。
2 歲版出現時會直接把路點亮，3 歲以上要自己找房間。

## 小遊戲（每件事一個，都是點和拖，不會失敗、沒有倒數）
### 自己的事
| 事情 | 房間 | 怎麼玩 | 學到 |
|---|---|---|---|
| 起床 | 房間 | 拉窗簾，太陽照進來；點角色伸懶腰、跳下床；把被子摺好 | 早晨的順序 |
| 刷牙 | 廁所 | 擠牙膏、牙刷在牙齒上來回刷（上面、下面、裡面都要），泡泡越來越多；漱口「噗～」 | 刷牙步驟 |
| 洗臉、洗手 | 廁所 | 開水、壓洗手乳、搓搓搓（手心手背指縫）、沖乾淨、擦毛巾、關水 | 洗手七步、省水 |
| 上廁所 | 廁所 | 脫褲子、坐馬桶、哼歌等一下、擦屁屁、拉褲子、沖水、洗手 | 如廁步驟 |
| 換衣服 | 房間 | 看窗外天氣，從衣櫃挑衣服拖到身上；穿錯會打噴嚏或流汗，再換；扣釦子、拉拉鍊 | 天氣和衣服 |
| 吃飯 | 廚房 | 擺碗筷（一人一副，數一數）、把飯菜肉水果拖到盤子（均衡）、用湯匙餵、擦嘴、碗拿去水槽 | 均衡飲食、數數 |
| 喝水 | 任何地方 | 水杯裝水、喝，身上的水壺慢慢變滿 | 多喝水 |
| 洗澡 | 廁所 | 試水溫（太燙會縮手）、放水、泡泡、沖水、擦乾、吹頭髮、擦乳液 | 洗澡步驟、安全 |
| 剪指甲 | 房間 | 一根一根手指點，喀嚓 | 衛生 |
| 睡午覺／睡覺 | 房間 | 拉窗簾、關燈、蓋被子、點故事書聽一段小故事（每天不同）、角色睡著 | 睡前的順序 |
| 量身高 | 房間 | 站到身高尺旁邊，貼紙表集滿會長高一格 | 長大 |

### 安全小常識（遇到時會出現，不嚇人）
熱的鍋子不能碰、插座不能戳、過馬路要牽手、坐車繫安全帶、地震躲桌下、不認識的東西不吃、打雷不怕。

## 點一點就會念名字
房子裡每樣東西（冰箱、牙刷、雨傘……）點一下都會念名字（家長可以加英文），像一本生活圖鑑，一共一百多樣。

## 獎勵：好習慣貼紙表和會長大的家
- 每做完一件事，貼紙表上那一格貼上一張貼紙（像幼兒園的集點表）；一天全部做完，小夥伴送一樣**房間的裝飾**（新的床單、牆上的畫、窗邊盆栽、燈），家慢慢變漂亮。
- 集滿一週，角色在**身高尺**上長高一格，衣櫃多一套衣服。
- 小夥伴也會長大一點點。
- 沒有排名、沒有扣分。

## 每次玩多久
- 家長設定，**預設 15 分鐘**。時間到了小角色也要睡覺，整個家變暗，要家長解開或等一個小時才能再玩。而且 APP 會說：「換你去做了！」把小朋友帶回真實生活。

## 家長模式（要過家長關卡）
- 名字、角色、第二個小朋友。
- 年齡（難度）、每次玩多久、要哪些作息（例如沒有上學就關掉）。
- 看每天做完哪些事、最常跳過哪一項。
- 聲音、念出來、英文。
- 以後的完整版購買只在這裡。

## 畫風：立體書風（草圖見 `docs/mockups/0_畫風選擇.png` 的 B）
像翻開的立體書：每個房間是一頁，紙片一層一層立起來，有紙的厚度和影子，顏色柔和（粉紅、薄荷、奶油黃）。角色是 Q 版的紙偶：頭大大的、大眼睛、紅臉頰；家具和時鐘上的圖案有小小的臉。和七個兄弟 APP 的畫風都不一樣（粗黑框貼紙、水彩繪本、黏土、寫實／色塊、三種卡通、等角小模型／孔版／蠟筆、羊毛氈／像素／果凍）。只做這一種。

## 聲音
- 每個時段有不同的背景音樂（早上輕快、中午活潑、晚上安靜的搖籃曲）。
- 每個動作有音效：刷牙沙沙、水龍頭、沖馬桶、吃飯「嗯～好吃」、拉窗簾、關燈「喀」、打哈欠、肚子咕嚕。
- 小夥伴有自己的叫聲。
- 全部用程式合成。

## 技術（和兄弟 APP 一樣）
- Flutter、Riverpod、flutter_svg、audioplayers、flutter_tts；存檔是一個 JSON 檔。
- 點和拖都用原始的手指事件（`Listener`）。
- 圖用 Python 畫 SVG（一份幾何，可以畫成三種畫風），聲音用 numpy 合成。
- 資安和兄弟 APP 一樣：不接受別的 APP 傳來的頁面、家長模式只能從家長關卡進去、不要任何權限。名字只存在手機裡。

## 以後上架和收費（和兄弟 APP 一樣）
- 免費下載：起床、刷牙、吃飯、睡覺四件事。
- 一次買斷完整版：全部作息和房間裝飾。購買只在家長模式。
